Strategy: collapse toolbar + source header + footer into a single editorial header. Title is the dominant typographic mark — caption lives as its subtitle in italic serif, so the title is never obscured by overlays. Color chips are a 24px dashed rail inside the code panel only; they don't encroach on preview space. Zoom pill auto-hides at 35% opacity, brightens on hover.

Typography: Fraunces (variable serif, optical sizing 144) for title + caption, Inter Tight for UI, JetBrains Mono for code. Palette: bone #f5f1ea, ink #1b1b1f, moss accent #3f6b54.

Chrome total: ~68px header (only band in embedded mode) — 61% reduction vs baseline's 176px. Minimap is suppressed in embedded, restored as a glass overlay top-right in fullscreen.
