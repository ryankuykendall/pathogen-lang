04 · Split Ribbon

PG radial-labels.pathogen

100%
PATHOGEN

Strategy: dissolve the global header and footer. Each panel owns a tight 28px ribbon carrying only its relevant controls. Code panel ribbon: PG language pill + filename + copy + inline color chips. Preview ribbon: title + caption (both visible, title prominent) + code-toggle/fullscreen/playground. The code-toggle lives on the preview side precisely because it must always be reachable — when you collapse the code, its ribbon folds away with it; you re-open the code from the preview ribbon. The PATHOGEN wordmark runs vertically along the right edge of the preview — an editorial flourish, not a claim on layout space.

Dirty-state affordance: when a color chip is edited, a small safety-orange · dot appears on it and a ↻ reset link slides in beside the chip group.

Typography: Space Mono (display title), Manrope (UI labels), JetBrains Mono (code). Palette: paper #fafaf7, iron #2a2b2e, safety orange #ff5a1f used only for dirty-state affordances. Hairline column divider.

Chrome total: ~28px per panel — 68% reduction vs baseline. Minimap appears top-left of preview in fullscreen.
