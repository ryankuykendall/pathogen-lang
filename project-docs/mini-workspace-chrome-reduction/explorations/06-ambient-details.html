Variation of 03 — Ambient Chrome. The ··· overflow on the right is replaced with a chevron on the left of the title, and the whole header row becomes a <details>/<summary>-style affordance. Click the header to toggle. No hover-reveal: the user has to commit.

Animation: the glass-blur bar is in document flow (not an absolute overlay) and height-animates from 0 to 44px — a vertical window-blind reveal that pushes the code + preview body downward rather than covering it. Chevron rotates 90° clockwise when open. After the height transition completes, overflow: visible is toggled via JS so dropdown tooltips can escape the bar.

Playground button: label removed, now icon-only with an aligned-right tooltip reading Open in playground workspace. Preserves prominence via the citrus-accent fill.

Chrome total: 28px resting / 72px open — same footprint as 03 but with an explicit click affordance and in-flow reveal. Typography & palette unchanged: Reddit Sans Condensed, Figtree, Geist Mono on near-black.
