radial-labels.pathogen

100%
PATHOGEN

Strategy: move the color swatches into the code editor. Each hex literal that backs a CSSVar() (the three @property-declared vars: #cc3333 behind --bar-all, #f6efe6 behind --bg-color, #1a1a2e behind --bar-top) gets a small circular chip adjacent to it — click the chip, the native color picker opens, the chart updates live. Other hexes (such as #2f2f2f or #d4c9b8 used as fixed colors) stay as plain text. The entire dedicated var row is eliminated. Reset appears as a floating button in the code panel only when any var is dirty.

Caption handling: hover the title to reveal the caption as a typeset tooltip. Fullscreen adds a 24px footer with PATHOGEN + caption so the caption is always visible when the user is focused.

Typography: IBM Plex Serif (title), IBM Plex Sans Condensed (UI chrome), IBM Plex Mono (code and filename). Palette: #fafbfc / #23272e, single accent teal #0c8f8f.

Chrome total: 32px top + 24px footer (fullscreen only) = ~32px in embedded — 82% reduction vs baseline. Minimap suppressed in embedded, present top-right in fullscreen. Click any hex chip in the code to see live update; Reset vars appears when dirty.
