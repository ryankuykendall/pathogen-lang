Polychrome Halo

R by @ryan-kuykendall Published May 14, 2026

Twelve concentric rings, each with its own gradient stroke, and a deliberate offset wedge cut from the upper-right — a study in what happens when ConicGradient meets PathBlocks at uneven angular tempo.

// Polychrome Halo — concentric rings with offset wedgelet radius = 280;let rings  = 12;let center = (400, 300);fn paletteAt(t) {  let hue    = 28 + t * 240;  let chroma = 0.18 - t * 0.06;  return oklch(0.74, chroma, hue);}for (i in 0..rings) {  let t      = i / rings;  let r      = radius * (1 - t * 0.92);  let stroke = 1.5 + t * 2.5;  circle(center, r)    .stroke(paletteAt(t), stroke);}// the wedge — asymmetric beatwedge(center, radius * 1.06, -22°, 30°)  .fill(oklch(0.99, 0, 0));
