# Calligraphy & Lettering Worksheets

**Tier:** physical-output · **Rubric:** Pop 3 · Pain 2 · Fit 4 · GapCost 4 · Adopters 2 = **192** · Longlist C7

## Snapshot
Practice sheets are parametric by definition — guideline grids of x-heights,
slant angles, and nib ladders — sold in volume on Etsy and Teachers Pay
Teachers as printable + Procreate bundles.

## Description
Calligraphy teachers and worksheet sellers producing guideline sheets (slant
grids for Copperplate at 55°, brush-lettering baselines, x-height ratios per
script), tracing alphabets, and drills. Market channels: Etsy (10-alphabet
bundles, 60+ page packs), TPT, teacher blogs (The Postman's Knock tier).
Formats: print PDF + Procreate import.

## Problems Pathogen could address
Every script has a guideline geometry (ascender/x-height/descender ratios,
slant angle, nib-width ladders) that sellers rebuild per page size and per
script in Illustrator. A guideline generator — script parameters in, letter-
size-graded sheet sets out — automates the whole non-artistic half. Dot-grid,
arc-drill, and flourish-practice geometries are similarly parametric.

## Commercial value
Real but modest: worksheet packs at $5–15 with steady volume; teacher
licensing; the generator itself as a seller tool. Feeds the planner/printable
economy rails (E2).

## Missing features
### Domain-specific [D]
- Script guideline models (ratio + slant presets for major scripts)
- Nib-width ladder rendering; drill-stroke pattern kit
- Procreate-friendly export sizing conventions
### General [G]
- Multi-page PDF; physical units; CLI batch (size-graded sets)

## Project ideas (as of 2026-10-07)
Tiered by Pathogen skill and readiness. Web-researched; a dated snapshot.

### Beginner — buildable today
- **Copperplate slant-grid sheet** — The staple free download of every
  pointed-pen teacher: baseline, waistline, ascender and descender rules
  crossed by 55° slant lines. In Pathogen it is a handful of parameters, with
  the ratios and the slant angle as named values and one PDF page out. Change
  two numbers and the same file becomes a Spencerian 52° sheet, which is the
  whole pitch in miniature.
- **Brush-lettering baseline sheet** — Brush-pen beginners practise on widely
  spaced rows with a dashed waistline, sold in large-pen and small-pen
  versions. Rows are a Grid, the dash pattern is a stroke setting, and row
  height is one parameter, so both pen sizes come from a single source. It
  suits a seller's first Pathogen file because nothing here needs more than
  lines, text and PDF export.
- **Faux-calligraphy alphabet tracing sheet** — Tracing sheets print an
  exemplar alphabet in pale grey over guidelines so learners can write on top
  of it. Text-to-path sets the letters from any loaded font, the guidelines
  sit on a second layer, and the stroke colour is one value. A seller can swap
  the font or the pangram and regenerate the page without redrawing anything
  in Procreate or Illustrator.

### Intermediate — several features, or one gap
- **Word and name tracing sheets** — Teachers personalise practice pages with
  a student's name or a weekly word list repeated down the sheet, each row
  fading from solid to dotted to blank. This combines text-to-path, a Grid of
  rows, per-row stroke styling and a loop over a word array. Every feature is
  shipped; the skill is composing them so that one edited list regenerates the
  whole page.
- **Envelope addressing guide** — Calligraphers addressing wedding envelopes
  slip a ruled card inside, or use a light pad, so lines of script stay level
  and centred. The card must match A7 or DL envelopes exactly, which runs into
  the one gap here: physical units. Until then the card is drawn in viewBox
  units and scaled at print time, which works but invites the errors Pathogen
  should remove.
- **Place-card and escort-card sheet** — Event calligraphers print faint
  baselines on card stock, several place cards to a sheet, then letter the
  names and trim. Grid lays out the cards, each cell carries its own centred
  guideline, and PDF export supplies crop marks for the guillotine. A name
  list could also be set in a script font as a pencil-weight underlay for
  consistent spacing across two hundred cards.

### Advanced — depends on a named gap
- **Basic-stroke drill workbook** — The best-known free worksheets are drill
  pages: entrance strokes, underturns, overturns, ovals and compound curves
  repeated along slanted guidelines. Drawing each stroke by hand in path
  commands is possible but tedious; the opportunity is the missing
  drill-stroke pattern kit [D], which would let a teacher name a stroke, a
  slant and a row count and receive a finished page.
- **Broad-edge nib-ladder sheets** — Italic, Foundational and Gothic hands
  measure letter height in nib widths, shown as a staircase of small squares
  at the margin, for example five widths of x-height for Italic. A sheet has
  to be regenerated for every nib size a student owns. Nib-width ladder
  rendering [D] is the named gap, and it would turn one script definition into
  a sheet for any pen.
- **Procreate guideline overlay pack** — Much lettering practice has moved to
  the iPad, where sellers bundle guideline sheets as transparent overlays
  sized for common Procreate canvases alongside the printable PDFs. Making
  both today means maintaining two hand-built sets that drift apart.
  Procreate-friendly export sizing conventions [D] is the gap; with it, one
  Pathogen source would emit the print sheet and the matching overlay
  together.
