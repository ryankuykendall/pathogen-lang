# Foam Armor & Cosplay Patterns

**Tier:** physical-output · **Rubric:** Pop 3 · Pain 4 · Fit 3 · GapCost 2 · Adopters 3 = **216** · Longlist A18

## Snapshot
EVA-foam armor is built from flat pattern pieces (helmets, breastplates,
bracers) sold as PDF+SVG/DXF packs — with the domain's core chore being
scaling patterns to a specific body, piece by piece.

## Description
Cosplayers and prop makers heat-shaping EVA foam from patterns. The pattern
economy (Etsy, Gumroad — Pretzl Cosplay tier sellers) ships PDF print packs
plus SVG/DXF for cutting machines, with part labels, build order, and
registration marks. Design happens in Illustrator or via 3D-model unwrapping
(Armorsmith is the domain's dedicated scaling tool). Community lives on
TikTok/YouTube build content.

## Problems Pathogen could address
Patterns are static sizes; fitting means scaling *per body measurement* — and
naive uniform scaling breaks (a bracer scales with wrist girth but not length
equally). Parametric patterns driven by a measurement table are the garment
post's thesis in foam. Part labelling, mirrored left/right pairs,
registration marks, and bevel-angle annotations (45° edges for joins) map to
labels and line classes. The 3D-unwrap ceiling is real (complex curved
armor), but a large share of pieces are developable flats.

## Commercial value
Active pattern-seller economy with multi-format packs already standard;
measurement-driven "fits you" patterns would be a visible tier upgrade;
convention workshop content.

## Missing features
### Domain-specific [D]
- Measurement-table-driven grading (wrist/forearm/bicep girths → bracer)
- Bevel-angle line classes (45°/90° edge annotations for foam joins)
- Mirrored pair + part-label kit with build-order numbering
- Multi-page tiled PDF at 100% with registration (shared need)
### General [G]
- Data import (measurement tables); physical units; modules (armor part
  libraries)

## User base
Cosplay is millions strong (r/cosplay ~1M+); foam-armor builders est.
200k–500k · confidence **L, unverified**. Pattern sellers the adopter tier.

## Community & current conversation (as of 2026-08-30)
- **Where they gather:** TikTok/YouTube build channels (the discovery layer),
  r/cosplayers and prop-making Discords, Etsy/Gumroad pattern shops,
  convention maker tracks.
- **Talking about right now:** multi-format pattern packs (PDF + SVG/DXF +
  build notes) are the professionalized norm; beginner-to-intermediate
  positioning dominates listings; steady helmet/breastplate/bracer canon.
  (etsy.com markets, gumroad shops, youtube build playlists)
- **Obsessed with:** clean bevels and seams, heat-forming technique, scaling
  patterns to fit, budget builds.
- **Blog content angles:** (1) a bracer graded from three measurements — the
  "pattern that fits *you*" story; (2) bevel angles as labelled line classes;
  (3) one pattern → print PDF + Cricut SVG pack.

## Pathogen fit today
Flat pattern geometry, mirroring, labels, exact-scale PDF all work; the
measurement-driven core waits on data import (GapCost 2), and curved-armor
unwrapping is out of scope.

## Proposed validation project
A parametric bracer: three girth measurements in, labelled mirrored pattern
pair with bevel classes and build numbering out — foam-built to verify fit
against a straight-scaled version.
