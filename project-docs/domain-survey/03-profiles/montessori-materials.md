# Montessori & Classroom Materials

**Tier:** physical-output · **Rubric:** Pop 2 · Pain 3 · Fit 4 · GapCost 3 · Adopters 2 = **144** · Longlist D5

## Snapshot
The Montessori-maker convergence is already happening — free laser-file
libraries carry dozens of Montessori toy templates and Etsy sells laser-cut
materials — but the materials' defining trait, dimensional exactness by
pedagogical spec, is served by no parametric tool.

## Description
Montessori teachers, homeschoolers, and Etsy material makers producing:
sandpaper-letter templates, movable-alphabet pieces, fraction circles/
skittles, geometry cabinet insets, number rods, printable three-part cards.
The DIY culture is large (900+-idea Pinterest printable boards; 10k+ laser
models indexed; 58+ free laser templates on file-library sites). Materials
follow AMI/AMS dimensional conventions — proportions are pedagogy.

## Problems Pathogen could address
Montessori materials are *specified* geometry: fraction insets must be
mathematically exact, geometry-cabinet shapes follow canonical dimension
sets, movable alphabets need consistent letterform sizing across the set.
Makers currently trace or copy files of varying fidelity. A spec-true
parametric library (with knob-hole placement, tray-fit tolerances) raises
the floor for the whole DIY ecosystem — and grading a set to a different
tray size is a parameter, not a redraw.

## Commercial value
Etsy material sellers (active market), homeschool curriculum bundles,
school-shop licensing. Modest; strategic overlap with D4's teachers-make-
users channel.

## Missing features
### Domain-specific [D]
- Spec libraries for canonical materials (fraction sets, insets, rods) with
  pedagogical dimension conventions
- Knob/tray-fit tolerance handling (material thickness again)
- Three-part-card layout kit (image + label + control cards)
### General [G]
- Physical units; modules (the spec library IS the value); multi-page PDF
  for card sets

  tolerances done right.

## Pathogen fit today

library are the work. Cousin domain to D4/A1; shares nearly all gates.

## Proposed validation project

tray fit at 3 mm ply, labels — cut and compared against a catalog-supplier
set.
