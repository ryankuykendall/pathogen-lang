# Guilloche & Certificate Art

**Tier:** data-driven · **Rubric:** Pop 1 · Pain 3 · Fit 5 · GapCost 4 · Adopters 4 = **240** · Longlist E3

## Snapshot
Spirograph-class parametric curves — rosettes, security borders, watch-dial
engine turning — are the purest expression-first geometry on the longlist,
with a small maker audience that already hunts for vector generators.

## Description
Makers engraving guilloche on lasers/CNC (watch-dial-style rosettes, CD
engraving experiments), certificate/diploma designers needing security-style
borders, and generative artists (100-day spirograph projects). Historic
significance: banknote/certificate engine turning. Current tooling: scattered
one-off generators (a GCMC gist, defunct web apps), Illustrator plugins,
Processing sketches — makers on CNC forums explicitly ask for vector
generators and find little.

## Problems Pathogen could address
Guilloche IS parametric equations rendered precisely — epitrochoids with
modulated amplitude, ring layouts, interference patterns. Incumbent gap is
not capability but *packaging*: no accessible tool outputs clean layered
vectors at engraving precision. Certificate borders (frames, rosette corners,
microtext-style line fills) are compositional kits atop the same math.

## Commercial value
Tiny direct market (engraving files, certificate templates, watch-hobby
niche) — the value is demonstrative: guilloche makes spectacular gallery
content that showcases precision, determinism, and expression-first syntax
better than any other domain. A "guilloche kit" module is marketing that
compiles.

## Project ideas (as of 2026-10-07)
Tiered by Pathogen skill and readiness. Web-researched; a dated snapshot.

### Beginner — buildable today
- **Single-ring spirograph rosette** — The classic first figure: one
  hypotrochoid or epitrochoid traced until it closes, the same curve the
  surviving web spirograph generators draw. In Pathogen it is a loop, two trig
  terms and a few named ratios, so changing one ratio redraws the whole
  rosette. It is the smallest honest showcase of expression-first syntax, and
  the output is clean enough for a pen plotter.
- **Moiré interference card** — Two near-identical line families, concentric
  rings or radiating waves, overlaid with a small offset so interference bands
  appear; generative artists print these as postcards. The piece needs only
  loops, trig and precise stroke placement, all shipped. Deterministic output
  means a numbered edition can be regenerated exactly, and each variation is
  one changed constant instead of a redrawn file.
- **Layered security seal** — The Illustrator-tutorial staple: a round seal
  built from several concentric guilloche rings around a blank center left for
  a title or date. Each ring is the same trig loop with a different amplitude
  and lobe count. Designers build it by hand with rotate-and-blend steps; in
  Pathogen ring count, lobes and radii are parameters, so a matching family of
  seals costs nothing extra.

### Intermediate — several features, or one gap
- **Color-layered rosette for laser engraving** — A multi-ring rosette with
  every ring in its own color, the way laser hobbyists assign separate power
  and speed settings per pass on brass or anodized aluminium. Loops, precision
  and colored strokes are shipped, and the vector imports into laser software
  directly. The one gap it meets is DXF/engraver export, for the CNC users
  whose toolchains do not accept SVG.
- **Guilloche watermark background** — The pale all-over wave lattice behind
  the text of diplomas, vouchers and gift certificates, sold as stock vector
  sets in A4, Letter and Legal versions. It combines a modulated wave loop,
  tiled repetition, a clipping frame and export at page size. One source
  regenerates every paper format, where stock sellers maintain a separate file
  per size and cannot change line density afterwards.
- **Hundred-day spirograph series** — A daily-variation project common among
  generative artists: one curve family, a hundred outputs. Deterministic
  hashing picks ratios, amplitude and ring count per day, so any day can be
  rebuilt exactly, and a captioned contact sheet collects the set for print.
  Everything used is shipped; finding good parameter ranges by editing numbers
  is slow, which is where the missing parameter sliders would help.

### Advanced — depends on a named gap
- **Engine-turned watch dial blank** — Hobby watchmakers engrave dial blanks
  with a sunburst or basket-weave center, a plain chapter ring and openings
  for sub-dials and a date window. It depends on the rosette/engine-turning
  kit for ready trochoid families and ring layouts, plus DXF/engraver export
  for small CNC mills. With both, a dial becomes a parametric file sized to a
  movement instead of a one-off drawing.
- **Banknote-style specimen sheet** — A fantasy banknote or share certificate
  with corner rosettes, a repeating edge border, vignette frames and
  denomination panels, the showpiece of security-print enthusiasts. It depends
  on the border/frame composition helpers, so corners and repeating edges
  close exactly at any sheet size. That is the opportunity: stock sets ship
  fixed A4 frames, while a Pathogen border would fit any proportion requested.
- **Live rosette explorer** — The defunct web generators that CNC-forum makers
  still ask about were slider toys: drag lobes, amplitude and phase, watch the
  figure change, download the vector. Rebuilding that in the playground
  depends on parameter sliders, the first general gap listed. A shareable
  explorer with clean layered vectors out is the packaging this niche lacks.
