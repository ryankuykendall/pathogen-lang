# Guilloche & Certificate Art

**Tier:** data-driven · **Rubric:** Pop 1 · Pain 3 · Fit 5 · GapCost 4 · Adopters 4 = **240** · Longlist E3

## Snapshot
Spirograph-class parametric curves — rosettes, security borders, watch-dial
engine turning — are the purest expression-first geometry on the longlist,
with a small maker audience that already hunts for vector generators.

## Description
Makers engraving guilloche on lasers/CNC (watch-dial-style rosettes, CD
engraving experiments), certificate/diploma designers needing security-style
borders, and generative artists (100-day spirograph projects). Historic
significance: banknote/certificate engine turning. Current tooling: scattered
one-off generators (a GCMC gist, defunct web apps), Illustrator plugins,
Processing sketches — makers on CNC forums explicitly ask for vector
generators and find little.

## Problems Pathogen could address
Guilloche IS parametric equations rendered precisely — epitrochoids with
modulated amplitude, ring layouts, interference patterns. Incumbent gap is
not capability but *packaging*: no accessible tool outputs clean layered
vectors at engraving precision. Certificate borders (frames, rosette corners,
microtext-style line fills) are compositional kits atop the same math.

## Commercial value
Tiny direct market (engraving files, certificate templates, watch-hobby
niche) — the value is demonstrative: guilloche makes spectacular gallery
content that showcases precision, determinism, and expression-first syntax
better than any other domain. A "guilloche kit" module is marketing that
compiles.
