# Model Railroading (Structures & Track Planning)

**Tier:** physical-output · **Rubric:** Pop 3 · Pain 3 · Fit 3 · GapCost 3 · Adopters 3 = **243** · Longlist A14

## Snapshot
An obsessive, tool-friendly hobby with two Pathogen-shaped halves: laser-cut
scale structures (flat-pack at 1:87) and track planning — where 2026 tool
reviews literally praise "parameterized geometry propagation" as a
differentiator.

## Description
Model railroaders building layouts in N/HO/O scales. Structures: laser-cut
building kits and scratch-building (board-and-batten walls, window/door
castings, brick sheets) — a mature kit industry plus Etsy cut-file sellers.
Track planning: AnyRail, SCARM, XTrackCAD, TrackPlanner.app — CAD tools with
manufacturer track libraries, turnout templates, and grade/clearance checks.
Community skews older, deeply committed, documentation-loving.

## Problems Pathogen could address
Structures are the wargaming-terrain problem at stricter scale discipline:
one prototype building should regenerate at N/HO/O with material thickness
re-solved and window spacing preserved — today each scale is a redraw.
Procedural wall textures (clapboard, brick courses) are Grid+noise work.
Track-side: templates for hand-laid track (tie spacing jigs, turnout
templates at NMRA specs) are parametric geometry the planning tools don't
print well.

## Commercial value
Structure kit/cut-file sellers; scratch-builder template packs; NMRA-spec
jig generators. The hobby spends generously; sellers are the wedge.

## Missing features
### Domain-specific [D]
- Scale-aware regeneration (1:160/1:87/1:48 with thickness re-solve)
- Architectural detail generators: clapboard, brick bond patterns, window
  muntins as procedural fills
- NMRA-standard track templates (tie spacing, turnout geometry)
### General [G]
- Physical units + named scale ratios; sheet nesting; DXF export; modules
  (architectural part libraries)

## User base
Est. 500k–1M active in North America/Europe (NMRA membership ~15k is the
committed core; the hobby is far larger) · confidence **L, unverified**.

## Community & current conversation (as of 2026-08-30)
- **Where they gather:** Trains.com/Model Railroader forums, r/modeltrains,
  NMRA divisions, JMRI/planning-tool user groups, YouTube layout builders.
- **Talking about right now:** track-planning software comparisons dominate
  tool discourse — 2026 reviews rank AnyRail/SCARM/XTrackCAD/TrackPlanner on
  *repeatable geometry edits* and "parameterized geometry propagation," i.e.
  the market is already asking for parametric; browser-based planning is the
  new entrant pattern. (trains.com, gitnux.org, wifitalents.com reviews)
- **Obsessed with:** prototype fidelity, era consistency, benchwork planning,
  operations sessions.
- **Blog content angles:** (1) one depot, three scales — regeneration with
  thickness re-solved; (2) brick bonds as procedural fills; (3) a hand-laid
  turnout template at NMRA spec.

## Pathogen fit today
Structure half fits like wargaming terrain (labels, noise, layers); track
half needs curve/easement work that's doable but conventions-heavy. Units
and scale ratios gate everything.

## Proposed validation project
An HO clapboard depot wall set with procedural siding and window cutouts,
regenerated at N scale — cut and compared against a commercial kit's fit
quality.
