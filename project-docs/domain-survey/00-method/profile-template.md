# Domain Profile Template

One page per domain. Every Stage 3 profile follows this structure exactly, so
profiles are diffable against each other.

```markdown
# <Domain name>

**Tier:** physical-output | data-driven · **Rubric:** Pop n · Pain n · Fit n · GapCost n · Adopters n = **product**

## Snapshot
One sentence: who makes what, and why Pathogen is interesting to them.

## Description
Who the practitioners are, what artifacts they produce, the current toolchain
(name names and prices), and where the output goes (machine, printer, screen).

## Problems Pathogen could address
Concrete recurring pains in the incumbent workflow, in the Cutting Room
"walking the pattern" style — what do they re-do by hand after every change?

## Commercial value
Who pays, for what: file/pattern marketplaces, SaaS, education/curriculum,
hardware-ecosystem placement. Rough size signals where available.

## Missing features
### Domain-specific [D]
The game-changers for this domain specifically.
### General [G]
Which of the shared requirements this domain needs most, and why.

## User base
Estimate · source or proxy · confidence (H/M/L) · early-adopter notes.

## Community & current conversation (as of YYYY-MM-DD)
Feeds the blog content pipeline — what would land as current, relevant, timely.
- **Where they gather:** subreddits, Discords, Facebook groups, forums,
  conferences, hashtags/platforms — with rough sizes.
- **What they're talking about right now:** live controversies, new hardware /
  software releases, platform changes, seasonal events. Web-verified, cited.
- **What they're obsessed with:** the evergreen passions — the techniques,
  debates, and status markers that never leave the front page.
- **Blog content angles:** 2–3 concrete post ideas that meet the community
  where its attention currently is.

⚠ This section is a *dated snapshot* — it goes stale by design. Re-verify
before commissioning any blog content from it.

## Pathogen fit today
What already works for this domain with current features (cut(), segment
labels, offset(), PDF bleed/crop-marks export, @font, deterministic noise/hash,
Grid, markers, text-to-path, …).

## Proposed validation project
A Cutting-Room-style demo artifact that would drive out this domain's real
friction log.
```
