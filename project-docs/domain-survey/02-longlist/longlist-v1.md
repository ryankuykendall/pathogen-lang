# Domain Longlist — v1 (Stage 2)

*2026-08-30. 50 domains in five clusters. Scores are provisional desk
estimates using `00-method/scoring-rubric.md` (Pop · Pain · Fit · GapCost ·
Adopters, each 1–5, product 1–3125); Stage 3 one-pagers verify populations and
may move scores. ⭐ = already profiled in `01-sample-domains/`.*

**Reference — already explored via the Cutting Room series (not counted):**
papercraft, jigsaw puzzles, garment patterns, stained glass. These four have
working demos and a friction log; their Stage 3 profiles can be back-filled
from the series if we want them in the matrix.

## Reading the scores

Product ≥ 400 = strong candidate · 200–399 = solid · < 200 = watchlist.
GapCost is *inverse* (5 = gaps are polish-level, 1 = engine work).
