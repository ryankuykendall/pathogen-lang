SVG-Path-Extended · v1.0

Code paths into pictures.

An expression-first language for SVG. Variables, control flow, gradients, layers, and a stdlib of geometric primitives — turning M 100 100 C… into something you'd actually want to maintain.

Open My Workspaces Read the docs

Open source · MIT licensed

The compiler is on GitHub.

Read the source, file an issue, send a pull request. The Lezer parser, evaluator, stdlib, and CLI all live in one repository — small enough to read in an afternoon.

github.com/ryankuykendall/svg-path-extended

CLI · Node + tsx

A single binary, anywhere.

Compile a file, pipe stdin, or eval inline. Output as a path string, full SVG, or annotated debug view. Add it to a Makefile and treat your graphics like build artefacts.

$ echo 'circle(100, 100, 50)' | svg-path-extended -
→ M 50 100 A 50 50 0 1 0 150 100 A 50 50 0 1 0 50 100 Z
npm install -g svg-path-extended
