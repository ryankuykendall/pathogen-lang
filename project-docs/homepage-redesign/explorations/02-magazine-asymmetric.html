SVG, but a language.

An expression-first toolchain for path-based graphics. Compose curves, define gradients, iterate on a sketch — without ever leaving your editor.

Open Source · MIT

The compiler is on GitHub.

github.com/ryankuykendall/svg-path-extended →

CLI · Node + tsx

A single binary, anywhere.

Compile a file, pipe stdin, or eval inline. Output as a path string, full SVG, or an annotated debug view.

$ echo 'circle(100, 100, 50)' | svg-path-extended -
→ M 50 100 A 50 50 0 1 0 150 100 A 50 50 0 1 0 50 100 Z
