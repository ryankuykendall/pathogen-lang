2 · Fullscreen capture

In fullscreen the camera button joins the right-hand chrome under Layers / Export / Refresh. It is filled with the accent color because it's the main action while iterating. After a capture, a small tray at the bottom right shows the most recent snapshots. Press Refresh then Snapshot repeatedly to see it fill.

3 · Workspace filmstrip

A collapsible strip under the editor and preview lists this workspace's snapshots, newest first. When collapsed it's a 32px row with a count and three tiny thumbnails. Clicking a frame opens the viewer (screen 5). View all → goes to /snapshots filtered to this workspace. The ✎ badge marks snapshots with a note.

4 · /snapshots — all snapshots

A new top-level page, linked from the Workspaces landing page and the workspace ⋮ menu. Cards are grouped by day and show a pre-rendered PNG thumbnail, so the page loads fast and nothing recompiles. Filter by workspace. A snapshot whose workspace was deleted keeps the old name with a deleted tag, and you can still open it, export it, or start a new workspace from it. Hover a card for the ⋯ menu.

5 · Snapshot viewer

Opens over the gallery or the workspace. The body is the existing <mini-workspace> (glass control bar, pan/zoom, code toggle). It loads the stored SVG and code, so nothing is compiled. Use ← / → or the arrows to step through snapshots, and the strip at the bottom to jump. Export… opens the normal Export modal (SVG / PNG / PDF) on this stored image. Start new workspace copies the code into a new workspace. Random values re-roll there, as the note on hover explains.
