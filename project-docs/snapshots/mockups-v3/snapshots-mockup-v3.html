3 · /workspace/:slugId/snapshots

v3The page uses the stock <mini-workspace> with its own glass bar, code toggle and pan/zoom, and adds nothing on top: no prev/next arrows, since the filmstrip already does that, and no custom overlays. The actions moved up into the breadcrumb bar: Copy code, Start new workspace, ⋯ (Rename, Open in editor, Delete) and Export…. "Back to editor" is gone because the breadcrumb already links back. Under the viewer, one quiet row holds the snapshot name, details and note. The filmstrip moves through snapshots by click or ← →, and the URL follows (…/snapshots/11).
