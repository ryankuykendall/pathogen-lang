# Blog Post Authoring Playbook

## General Process

1. Author and review 250-word synopsis for each post (including title)
2. Assemble and review code examples (BBWPs + mini-workspaces)
   a. Rich labeling/text where appropriate
   b. Rendered SVGs include relevant schematic overlays explaining functionality and clarifying intent
   c. Liberal interactive code examples to accelerate user learning
   d. Visually rich, elegant, beautiful, sophisticated — elevating the Pathogen brand
3. Author and review draft blog post incorporating code examples in mini-workspaces
   a. Liberal links to other blog posts and documentation
   b. Available for review on dev:website
4. Agentic review round table
   a. Principal UX Designer (UXD) — top-tier company, cutting-edge UX tools expertise
   b. Principal UX Engineer/Design Technologist (UXE) — front-end, interactive experiences, 2D vector graphics tools
   c. Sr. Staff Product Manager (PM) — design tooling trends, market opportunities, unmet user needs
   d. Each role: strengths/weaknesses assessment → peer critique of other assessments
5. Final version incorporating all reviewer feedback
6. Push to dev:website, Puppeteer link checking, fix broken links, rebuild

## Multi-Part Series Notes

1. Posts published on different days (preserve desired order)
2. Table of contents at top showing series entries + current position
3. Subtitle: "Part <number> in our series on <topic or feature area>"
