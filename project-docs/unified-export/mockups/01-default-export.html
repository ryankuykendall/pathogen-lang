Design notes — default state

  • Retitled “Export” — this is now the only export workflow; opened by the ⋮ menu Export item or Ctrl/Cmd+Shift+E.
  • Format is the first decision, moved to the top with a third option: SVG · PNG · PDF. The download button echoes the choice (“Download SVG”).
  • Include legend defaults OFF — Name / Description / Date / Creator / Code fields only appear when it’s switched on (see mockup 02).
  • Watermark — with the legend off, the artwork carries a small Created in pathogen.studio line in its bottom-right corner (#94a3b8, Inter + Baumans, same brand pattern as the legend footer). It appears in the live preview so there are no surprises at download time.
  • Snap controls hidden — the zoom bar’s Snap toggle only matters when a legend can be dragged, so it appears only when the legend is on.
  • Advanced Export Settings (grid, grid color, precision) unchanged, collapsed by default.
