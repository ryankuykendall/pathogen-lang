Design notes — menu + watermark

  • Single Export entry. data-action="export" dispatches open-export; the modal opens for every format. “Export with Legend” and the old source-save code path are removed.
  • Keyboard: Ctrl/Cmd+Shift+E opens Export. Ctrl/Cmd+S stays an autosave flush (its old tooltip claiming it exported was wrong).
  • Watermark color #94a3b8 is a mid-slate chosen to be quiet on both dark and light artwork — visible in both close-ups above, dominant in neither. It sits inside the artwork’s bottom-right corner (10 units of padding, scaled with the legend’s unit system).
  • Fixed position v1 — not draggable, no opt-out (it’s the attribution that replaces the legend footer). If real artwork ever collides with it, a corner selector is the planned v1.1 escape hatch.
  • The watermark appears in the modal’s live preview, so what you download is exactly what you saw.
