Design notes — PNG format

  • Third format option. Selecting PNG reveals a .png-settings panel styled like the existing PDF panel; the download button reads “Download PNG”.
  • Scale presets 1× / 2× (default) / 4× of the artwork’s viewBox units, plus Custom width which reveals a pixel-width field; height always follows the aspect ratio. A live summary line shows the computed pixel dimensions (same pattern as the PDF size summary). Sizes clamp to a 16,384 px max side with an inline error state.
  • Transparent background omits the workspace background color; the preview swaps in a checkerboard so the transparent region is obvious before download.
  • Everything composes: legend and watermark work exactly as in SVG — whatever the preview shows is rasterized, fonts included.
  • Advanced settings (grid, precision) apply to PNG too — the grid rasterizes if enabled.
