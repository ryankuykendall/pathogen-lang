Design notes — legend on

  • Include legend ON reveals a grouped legend settings panel: Name, Description, Export Date, Creator, the Syntax highlighting checkbox, and the read-only source listing. Turning the switch off collapses the whole group (mockup 01).
  • Syntax highlighting defaults ON. Colors are the exact light-theme --code-* print palette (keyword #6d3aa6 · function #a83d80 · number #d97a6e · string #5a8a72…) inlined as literal fill attributes on per-token tspans — they survive SVG serialization, PDF text outlining, and PNG rasterization identically.
  • No italics in the export — the editor styles comments/functions italic, but the PDF outliner renders upright glyphs, so the export palette uses color + weight only. The legend card is always white, so only the light palette is needed.
  • Field label renamed from “SVGX Code” to “Source Code”.
  • Snap controls return in the zoom bar when the legend is on (the card is draggable/resizable, as today).
  • Legend footer keeps the Created in pathogen.studio brand line, so no separate corner watermark is added when the legend is on.
