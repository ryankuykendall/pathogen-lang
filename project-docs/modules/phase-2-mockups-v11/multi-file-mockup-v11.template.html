  • One zero-state, in the editor. Every button and every "why" is there. The preview draws the program, or stays blank; it keeps only its own chrome (the inspector toggle).
  • With a main (states 1 to 3), the zero-state says which file is the main and opens it, whatever the preview shows (your answer 1). With the tree hidden, Show files is beside it.
  • With no program (states 4 to 6), the zero-state says why nothing draws, and offers New program, the only button on screen. Its line says the new program will be the main.
  • A library open, and no program (state 7): a file is open, so there's no zero-state, and the preview is blank. What already exists says what happened: the status in the breadcrumb ("No program", which explains itself on hover) and the message after the delete. The + in the Files header adds a program, as always.
  • For this release. If the preview needs its own message later, it can come back.
