G · The program chip, beside the zoom controls chosen in your v3 review

  • The chip names the program shown. Click it for the list, which opens upward: each program with a miniature, its name, its path, and a check on the one shown. The entry point comes first.
  • Click a row to show that program. Hover a row for "Open in the editor", which opens the file and leaves the preview alone (state 2).
  • The dot before a name: that program uses the file you're editing. With the bottom line gone, the dot's tooltip is what explains it.
  • Editing a library (state 3): the preview stays on what you chose. Programs that use the library get the dot; the ones not shown spin until they redraw.
  • Editing a program that isn't shown (state 4): the preview stays on main, so typing in try-sizes doesn't change it. In the list, try-sizes has the dot.
  • An error in another program (state 5): a red dot on the chip; the row says where it failed.
  • Zoomed in (state 6): there is no navigator now (no minimap, no strip). Drag the drawing to pan; Fit takes you back.

E · The entry point, and the main badge from your v3 review

  • main.pathogen is the entry point by convention, and nothing marks it.
  • "Set as primary" in a program's row menu (state 1) makes another file the entry point. That file gets a main badge, in the tree and in the chip's list (state 2). main.pathogen is then an ordinary program, with no badge.
  • On main.pathogen, the same item puts the convention back, and the badge goes.
  • Setting the entry point doesn't change the preview: in state 2 the chip still shows main.
  • Export (state 3): the Project button is a stub here (dashed). Its workflow is step 2g in 42-phase-2-order.md: the .zip, pathogen.json's main, importing a folder, and which program SVG, PNG and PDF use.
  • Renaming a file rewrites the import paths in the other files (step 2d). The entry point keeps its role under a new name; renaming main.pathogen to poster.pathogen gives poster.pathogen the badge.
  • Deleting the entry point: main.pathogen takes over if there is one; if not, you're asked which program does.
  • Open: one word. The badge and pathogen.json say main; the menu says "primary".
