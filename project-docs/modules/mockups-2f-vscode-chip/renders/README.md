# Renders for the 2f mockup

The CLI's drawings of `../gears-project/`'s programs, used as the mockup's preview and miniatures:

    npx tsx src/cli.ts project-docs/modules/mockups-2f-vscode-chip/gears-project/<program>.pathogen \
      --output-svg-file=project-docs/modules/mockups-2f-vscode-chip/renders/<name>.svg \
      --png=project-docs/modules/mockups-2f-vscode-chip/renders/<name>.png
