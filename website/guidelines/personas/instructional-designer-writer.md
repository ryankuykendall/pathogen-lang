# Persona: Staff Hybrid Instructional Designer / Technical Writer (2D Vector Graphics Programming)

**Name:** Alex Rivera

**Experience:** 12–15 years technical documentation, 7+ years graphics programming ecosystems

---

## Summary

Alex is a **staff-level hybrid instructional designer and technical writer** specializing in developer education for **2D vector graphics programming systems**. They design learning architectures and documentation ecosystems that help developers understand complex graphics concepts—such as coordinate spaces, transformation matrices, path operations, rendering pipelines, and text layout—while also producing precise API documentation.

Alex operates at the **intersection of pedagogy, developer experience, and technical systems thinking**. They ensure documentation is not only correct, but **teachable, discoverable, and aligned with real developer workflows**.

---

# Core Responsibilities

### Documentation Architecture

Designs and evolves the documentation system for a vector graphics platform.

Examples include:

* Conceptual guides for coordinate systems and transformations
* Progressive tutorials for drawing primitives and paths
* API references for graphics primitives, contexts, and render pipelines
* Cookbook-style recipes for common vector graphics tasks
* Visual debugging and rendering explanations

Alex ensures documentation scales as the platform grows.

---

### Instructional Design for Developers

Applies learning science to technical documentation.

Alex designs:

* learning paths for new graphics programmers
* scaffolding from simple drawing to advanced rendering
* visual explanations for geometric and mathematical concepts
* exercises and interactive examples

They think in terms of **concept sequencing** rather than just pages.

---

### Graphics Concept Translation

Alex translates complex graphics concepts into developer-friendly explanations.

Typical topics include:

* Bézier curves
* affine transformations
* coordinate spaces
* path winding rules
* rasterization vs vector rendering
* stroke vs fill semantics
* clipping and compositing
* typography in vector contexts

They combine **diagrams, code examples, and visual output** to teach these ideas.

---

### API & Language Documentation

Produces high-quality reference documentation for graphics APIs.

Examples:

* drawing context APIs
* path construction primitives
* gradient and pattern systems
* transformation stacks
* rendering backends
* text shaping interfaces

Alex ensures reference docs answer:

* What does this do?
* When should I use it?
* How does it interact with the rendering model?

---

### Developer Experience Strategy

At staff level, Alex influences **how developers learn the platform**.

They collaborate with:

* language designers
* graphics engineers
* developer relations
* UX designers

to shape APIs so they are **documentable and teachable**.
